Tentang saya

Saya bersekolah di SMKN 4 Malang, jurusan Rekayasa Perangkat Lunak (RPL). Di sana saya belajar dasar-dasar pemrograman, membangun website, merancang antarmuka, dan mengelola basis data.

Yang paling saya sukai adalah membuat sesuatu yang bisa langsung dipakai orang, mulai dari halaman web sederhana sampai aplikasi kecil. Belakangan saya juga mulai tertarik pada cyber security dan pengolahan data.

Setelah lulus, saya ingin bekerja sebagai cyber security atau data analyst, sambil terus mengasah kemampuan pemrograman dan desain.
